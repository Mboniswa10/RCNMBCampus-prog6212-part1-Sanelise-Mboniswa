### Requirements

- SQL Server
- SQL Server Management Studio

### Database Setup

1. Open SQL Server Management Studio.
2. Connect to your SQL Server instance.
3. Open `docs/SQLQuery1.sql`.
4. Execute the SQL script.
5. The script will create the `RaceDay` database.
6. The script will create all required tables.
7. Sample data will automatically be inserted.
8. Run the verification queries at the bottom of the script.
